# 取证与发现判定

## 证据记录

为每次评估记录页面、采集日期和时区、视口与缩放、浏览器、桌面/移动模拟或真机、登录和 cookie 状态、工具可用性。加载感受额外记录网络与缓存条件；无法控制时写“未控制”，避免跨网络条件做速度比较。

每条证据包含：`编号 / URL或输入文件 / 视口 / 状态或操作步骤 / 截图或记录位置 / 事实观察`。截图需要包含相关上下文；保留原图，报告中可裁切突出问题。只保存与审阅有关的公开内容；公开样例使用合成材料或明确获准、已脱敏的材料。

| 输入能力 | 可以支持 | 需要补证据才能判断 |
|---|---|---|
| HTML/Markdown | 文案、链接声明、标签与原始属性观察 | 视觉布局、实际字体、当前可见性、点击效果、加载和动效 |
| 单张截图/设计稿 | 该画面中的层级、密度、表达和图像风格 | 未展示区域、响应式、真实命中尺寸、CSS 对比度、交互和性能 |
| 桌面+移动完整截图 | 两种视口的布局和静态信息呈现 | 点击、键盘、加载过程、动效及 reduced-motion |
| 浏览器与 DOM | 实际布局、样式测量、交互复现 | 表单后端收件、真实用户整体性能、未取证的设备/页面 |
| 用户提供的实测数据 | 对应日期、设备与范围的指标 | 当前版本或其他网络/用户群体的同样表现 |

延迟加载、动画初始透明状态或未打开的菜单可能导致截图缺内容。先滚动、等待相应内容出现或打开实际状态；可复现的缺失才作为当前缺陷。只看过首页时，不称“全站字体混乱”“所有 CTA 失效”等。

## 严重程度

- **Block**：已确认妨碍本次关键任务或造成严重错误表达，例如移动遮罩持续挡住唯一询盘入口、主 CTA 在实际操作中无效、公开关键证明已确认属于无关主体且被当作自身证明。记录环境、步骤、预期、实际与复现证据。高总分也不能抵消 Block。
- **Improve**：任务可完成，但存在明确理解/阅读/操作成本；说明优先级与影响推断，避免把风格偏好包装为业务效果。
- **Keep**：有证据表明能帮助任务的设计，指出应该保留的元素和原因。
- **待核实**：存在疑点，证据不够或需要主体关系、授权、后端等信息；写出最小验证动作。

Block 是当前检查范围内的关键任务障碍；最终是否上线还取决于业务、功能、安全等独立验收。本技能不签发上线许可或要求整站重构。

## 常见线索如何判

| 线索 | 实际核对 | 合理处置 |
|---|---|---|
| AI 工具名称出现在文件名 | 图片是否可见、真实内容是否有伪影/错误工艺/误导，文件名是否作为正文暴露 | 文件名本身不扣分、不判 Block；可见生成残留通常是 Improve，严重误导另按证据判断 |
| 认证图或 alt 中有不同公司名 | 打开图片、检查证书主体与有效期等可见信息；核实品牌、关联公司或被授权主体的关系 | 关系未知先待核实，不能仅按文件名断言盗用或伪造 |
| 主 CTA 的 href 为 #、空值或缺少链接 | 实际点击/键盘是否打开弹窗、执行按钮功能或跳到正确位置；记录语义及可访问名称 | 能完成动作就不叫死链；关键动作可复现失败才判 Block |
| 没有 WhatsApp | 目标市场与买家习惯，邮箱、电话、表单或其他渠道是否易用 | 合适渠道已覆盖就无需扣分；增加 WhatsApp 是业务选择 |
| 中文或其他语言文本 | 目标语言、正文用途、可见性，以及品牌名、地址、官方文件等合理保留 | 影响目标用户理解的未翻译内容可改进；不能把任何非英文或空装饰 alt 判故障 |
| Lorem ipsum 或拼写问题 | 是否是用户看到的正式内容、是否在示例/引用中、是否改变产品或操作含义 | 一般残留按范围给 Improve；关键任务被误导或破坏才升级 Block |
| 多套 Logo 或字体 | 是否为深浅背景版本、多语言字形回退、子品牌或有意的编辑式层级 | 按合理性与使用一致性判断，不能只数文件或字体数量 |
| PNG/JPEG、视频、某个前端框架 | 当前网络下实际请求、呈现顺序、文件大小和交互表现 | 记录可测事实；不从扩展名或框架推断秒数、CWV 或“必然慢” |
| CTA 缺乏明显差异 | 可见状态、背景、控件样式、聚焦及操作结果 | 精确对比度需测量；视觉不突出可报告观察，不宣称 WCAG 不合格 |

## 保存与授权

报告和证据写入用户指定的项目目录；没有指定时选当前项目下清楚命名的评估目录。技能安装目录仅作参考，不存真实评估日志。客户端不支持本地文件时交付对话报告并说明未保存证据件。向飞书、GitHub 或其他外部服务发布报告，遵循本次用户授权；执行本技能本身不代表发布授权。
