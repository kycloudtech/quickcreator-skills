# 证据与工具路线

采集前读取。优先已有工具；按所需能力选择底层技能，不要求它们全部安装，也不自动执行其上层全套审计。

## 选择能力

| 需要的信息 | 可用能力 | 没有时如何处理 |
|---|---|---|
| 页面正文/HTML/元数据 | 当前助手的网页读取、浏览器或公开 HTTP GET | 用户提供正文/源码；仍不足则标不可读，不按内容空白评分 |
| 动态CTA、表单、手机布局 | 环境支持的浏览器工具 | 只报告源码或桌面可确认的信息，交互未验证 |
| 搜索结果 | 当前可用网页搜索，记录提供方、市场和语言 | 省略搜索表现判断，继续页面体检 |
| AI回答 | 用户要求时使用可保存完整回答与引用的工具，或用户提供原始记录 | 标平台表现“未实测”，继续内容准备度评估 |
| 特定技术故障 | 本包的 check-crawlability / page-seo-inspector，可选安装 | 有证据才做有限追加，不要求全部安装 |
| 交付格式转换 | 用户要求时用当前可用文档/PDF工具 | 默认Markdown，不为未要求的格式阻塞交付 |

上述四个公开 Skill 不依赖私有服务、共享凭证或付费排名库。先确认当前工具及用法，不把不存在的工具写成已执行；外部能力可能有费用，按用户已有授权使用。

## 数据采集口径

每次运行记录：目标URL、最终URL、品牌别名和关联域、经营角色与出处、假设市场/语言、检查日期、页面清单、搜索问题清单、AI问题×平台计划与实际完成情况、当前限制。

把“本轮执行时间”和“原始数据采集时间”分别记录。检查当前工具缓存设置；不能刷新或原采集时间不明时，标为缓存/采集时间未知，不以运行日期代替。网页发布日期也不是本次抓取时间。

搜索记录至少包括查询原文、提供方、明确设置或无法控制的市场/语言、检查时间、结果范围、命中URL与位置。非标准SERP工具无法给可靠自然位次时只记录“返回中出现”，不硬写第1。

AI记录至少包括问题原文、平台、实际查询提供方/接口、设置的地区/语言、时间、完整回答、引用列表、执行状态。接口指定“US”未必能证明消费者前台的真实位置，应表述为“以美国英语采购场景查询”。聚合查询/API结果与消费者前台可能不同，保留取得方式和样本边界。

品牌别名来自官网和可核查关系，不能把所有相似拼写都算命中。引用URL去片段后再统计独立页面；重复文字片段不等于多个来源。

## 关键问题的取证强度

- **访问失败**：先区分DNS、TLS、HTTP错误、WAF和正文错误。可用另一个独立客户端交叉验证；只在一个环境失败则限定结论，不说全站宕机。
- **HTTPS故障**：可检验同站公开HTTP内容以区分内容存在与TLS配置，但不能因此判HTTPS正常。不绕过浏览器安全警告。
- **内容缺失**：先看正文，再按需检查相关图片、PDF、标签页；样本有说明就保留优点，不能只挑最差页面代表全站。
- **CTA/表单**：只读展开和导航可验证；未提交不证明收件正常/失败。脚本与星号必填标记、原生required属性分开记录。
- **主域关系**：观察canonical、跳转、名称和联系方式；法律/经营关系未核实时不实施或推荐立即强制迁移。
- **第三方指标**：保存错误响应与合法空响应区别；估算/覆盖不足不能转成实际UV、CTR、询盘或损失。
- **同业页面**：只读具体对比模块，表述“这个页面公开了什么”。不从竞争对手自述认证/交期推导真实优势。

关键否定结论应有足够复核，但不做无限探测。临时服务失败重试一次仍不行，换一个可用来源或标未验证。网站访问受阻时可先做搜索线索和需要核实的事项，不拿旧快照当现状。

## 范围控制

默认先读4–6页；有搜索能力时补1组品牌词、2–3个采购词。用户要求平台实测且有可用工具时，再做3个GEO问题×最多2个可用平台。数字是首轮预算范围，不是“凑满即完成”指标。

仅在会改变优先级时扩大：疑似主域问题、样本反例、关键页面错误需要验证。三项可靠重大问题已足以沟通时无需追求查尽所有缺陷。

全量抓站、WHOIS、外链矩阵、多个国家、多轮AI重复采样、完整关键词规划均不是默认必做。若用户要求深诊断，再明确范围转到对应专业流程。
